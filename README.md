# Planning and PDDL — website

Website of the open textbook **Planning and PDDL: Modeling problems for automated planners, from
PDDL 1.2 to PDDL+** (English) / **Planificación y PDDL** (Spanish), with the PDF of the book and
the lecture slides in both languages.

Site: https://fmrico.github.io/book_pddl_web/ (English) · https://fmrico.github.io/book_pddl_web/es/ (Spanish)

## Layout

```
index.html, es/index.html, sitemap.xml   generated by build.py (do not edit by hand)
build.py                                 texts of both languages and the page template
styles.css                               style
pdf/en, pdf/es                           book and slides
img/en, img/es                           cover and slide thumbnails (first page of each PDF)
robots.txt, .nojekyll                    for search engines and GitHub Pages
```

To update: replace the PDFs and thumbnails, edit `build.py` if needed (version, date, texts),
and run `python3 build.py`. Thumbnails: `pdftoppm -png -f 1 -l 1 -scale-to-x 640 -scale-to-y -1
-singlefile FILE.pdf img/en/slides/NAME`.
